# 📼 CLOTHES-O-MATIC '95 [MENSWEAR EDITION v4.0]
> **Cher Horowitz's Iconic *Clueless* (1995) Wardrobe Reimagined for Modern Menswear**  
> *Featuring a Realistic 3D Sculpted Studio Mannequin, Personal Body Photo Fitting, and the Atelier Sartorial AI Stylist.*

---

## 🌟 Overview

Inspired by the legendary wardrobe software used by Cher Horowitz in the 1995 cult classic **Clueless**, **Clothes-O-Matic '95** is an interactive, high-fashion web application built specifically for modern menswear. 

It blends authentic Windows 95 desktop nostalgia—complete with toggleable CRT scanlines, mechanical carousel steppers, and retro Web Audio synthesizer chimes—with modern sartorial intelligence, realistic 3D perspective mannequin rendering, and personal photo fitting calibration.

---

## ✨ Key Features

### 🕺 1. Realistic 3D Sculpted Studio Mannequin
- **Anatomical Depth & Lighting:** Sculpted muscular contours (pectorals, deltoids, clavicle, abdominal planes, quadriceps) rendered with 3D ambient occlusion, specular highlights, and studio floor perspective.
- **Interactive 3D Turntable:** Rotate the mannequin in real-time between:
  - `0° Front View` — Full frontal alignment and lapel symmetry
  - `35° Dynamic ¾ Turn` — Highlights side pleat fluidity, jacket flare, and dimensional depth
  - `90° Profile View` — Inspect posture line and trouser hem stacking over footwear
- **3 Studio Lighting Modes:**
  - `Studio Light` — High-key commercial studio illumination
  - `Chiaroscuro` — Directional key light with deep editorial shadow falloff
  - `Neon 90s` — Cyberpunk teal rim lighting with magenta accents

---

### 📸 2. Personal Body Photo Upload & Fitting Calibrator
- **Real Body Fitting:** Upload a photo of your own body (full-length or torso) directly from your device or camera.
- **Physique Presets:** Switch between *3D Sculpted Studio*, *Tall / Lean Frame*, *Athletic Broad V-Taper*, or *Relaxed Streetwear*.
- **Precision Calibration Controls:**
  - `Garment Scale` (80% to 125%)
  - `Vertical Offset (Y)` (-40px to +40px)
  - `Horizontal Offset (X)` (-30px to +30px)
  - `Layer Transparency` (Ghost fitting mode)
  - `3D Alignment Wireframe Guide`

### 🧠 4. Deep Fashion Intelligence & Live Critique Engine
- **Sartorial Rule of Thirds:** Evaluates silhouette dynamics (e.g. cropped boxy tops over wide puddle trousers vs top-heavy imbalance).
- **Tactile Fabric Synergy:** Analyzes textural interplay (e.g. silk + linen, wool + polished leather, 500GSM fleece + duck canvas).
- **Color Temperature & Tonal Depth:** Measures monochromatic depth, warm-cool counterpoints, and chromatic harmony.
- **Clueless Alarm System:**
  - 🚨 **"MIS-MATCH!"** — Triggers flashing red/yellow klaxon, harsh buzzer sound, and animated mannequin shake when severe clashing occurs.
  - 🏆 **"MATCH!"** — Triggers triumphant C-Major arpeggio fanfare, cohesion score (up to 100%), and tailored styling secrets.
- **Taste Profile Memory:** Automatically stores your diagnosed archetype and aesthetic preferences in `localStorage`.

## 💻 Tech Stack

- **Framework:** React 18 & TypeScript
- **Styling:** Tailwind CSS & Windows 95 Bevel Design System
- **Icons:** Lucide React
- **Audio:** Web Audio API (Pure synthesizer — zero external audio dependencies)
- **Bundler:** Vite 5

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ilikeapplesandbananas/digital-wardrobe.git

# Navigate to project directory
cd digital-wardrobe

# Install dependencies
npm install

# Start development server
npm run dev
```

Open your browser and navigate to:
```
http://localhost:8080/
```
